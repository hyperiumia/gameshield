# Roadmap

## Phase 1 — Observe (v1, current)
- Edge flight recorder + ingestion + storage
- Timeline per player / item / transaction
- Evidence export (the "black box" promise)
- 3 pilot servers, measured CPU/RAM/event volume

## Phase 2 — Alert
- Simple, explainable rules: money creation without origin,
  cascade dupes, chained transfers, coordinated accounts
- Dashboard (apps/web)
- EU data residency option

## Phase 3 — Respond
- Configurable actions: flag, freeze assets, require review
- Rollback assistance

## Phase 4 — Reputation (shared network)
- Weighted shared signals, human review, appeals
- Privacy framework + DPAs in place before launch

## 30-day plan (from scaffold)
- Days 1-5: event map + edge agent skeleton + lawyer on distribution channel
- Days 6-15: ingestion + storage + 3 alert rules
- Days 16-22: timeline panel + evidence export + demo incident
- Days 23-30: pilot on 3 servers + presentation kit
